# MementoCare AI — Adaptive AI & Bounded Intelligence

## 1. Core Principles

MementoCare AI employs bounded AI intelligence coupled with a deterministic rules engine:
1. **Explainable Performance Evaluation:** Evaluates accuracy (45%), normalized speed (25%), consistency (20%), and assistance efficiency (10%).
2. **Deterministic Difficulty Transitions:** Transparent thresholds ($\ge 85 \rightarrow +1$ Level, $70\text{--}84 \rightarrow$ Maintain, $50\text{--}69 \rightarrow -1$ Level, $< 50 \rightarrow$ Simplify & Support).
3. **Bounded Activity Generation:** Transforms caregiver-approved memory descriptions into multiple-choice recall questions using strict JSON schemas with zero hallucinations.
4. **Resilient Local Fallbacks:** If the AI API is unavailable, the platform automatically generates activities from pre-approved local templates.
