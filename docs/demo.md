# MementoCare AI — Platform Demonstration Script

## Persona
- **Demo Senior:** Abeni (72 years old, Guwahati, Assam)
- **Caregiver:** Priyanka Borah (Daughter)
- **Assigned Clinician:** Dr. Ananya Sharma (GMCH)

---

## 90-Second Step-by-Step Flow

### 0–8 seconds: Patient Profile & Orientation
- **Action:** Open `Today` screen on Senior Tablet.
- **Narration:** *"This is Abeni, an elderly user living in a region where specialised cognitive support can be difficult to reach."*
- **Visual:** Clean, high-contrast banner with location, time, and large touch targets.

### 8–16 seconds: Voice Greeting & Today Hub
- **Action:** Tap "Listen" or observe spoken welcome.
- **Narration:** *"A warm voice greeting welcomes Abeni in her native language, presenting daily hydration and reminder prompts."*

### 16–28 seconds: Caregiver-Approved Personal Memory
- **Action:** View photo of daughter Priyanka sharing Assam veranda tea.
- **Narration:** *"Instead of generic games, Abeni connects with verified photographs uploaded and approved by her daughter Priyanka."*

### 28–40 seconds: Personal Memory Engagement & Voice Input
- **Action:** Launch Personal Memory Game. Tap "Voice Answer" or tap option.
- **Narration:** *"Abeni answers gentle questions by voice or large tactile buttons with comforting chime feedback."*

### 40–50 seconds: Explainable Performance Breakdown
- **Action:** View interaction summary (Accuracy: 100%, Speed: 85%, Assistance: None).
- **Narration:** *"Performance is evaluated using explainable weights without intimidating medical scoring."*

### 50–57 seconds: Adaptive Engine Difficulty Transition
- **Action:** Observe adaptive progression (+1 level) with human-readable explanation.
- **Narration:** *"Because engagement was strong, the deterministic rules engine adapts by one level."*

### 57–68 seconds: Monsoon Blackout Simulation (Offline Mode)
- **Action:** Toggle Offline Mode. Complete Memory Cards activity.
- **Narration:** *"Internet is toggled OFF. The session executes smoothly and saves to the on-device SQLite outbox."*
- **Visual:** Banner displays *"Offline Mode — Result saved locally"*.

### 68–77 seconds: Network Reconnection & Outbox Sync
- **Action:** Toggle Online Mode and tap "Sync".
- **Narration:** *"When connectivity returns, outbox events synchronize with the server with idempotency protection."*
- **Visual:** Indicator turns green: *"Synchronised successfully"*.

### 77–86 seconds: Caregiver Dashboard & Engagement Trends
- **Action:** Switch to Caregiver Portal.
- **Narration:** *"Caregiver Priyanka reviews longitudinal engagement trends, reminder adherence, and approves new memory drafts."*

### 86–90 seconds: Statutory Medical Safety Boundary
- **Action:** Review footer notice.
- **Narration:** *"MementoCare AI supports cognitive engagement and care coordination. It does not replace doctors."*
